# Планировщик задач (Todo-лист)

## Описание проекта

Это веб-сервер на Go, который реализует функциональность планировщика задач (аналог TODO-листа). Проект выполнен в рамках дипломной работы. 

Сервер позволяет создавать, редактировать, удалять и отмечать задачи как выполненные. Задачи могут быть как одноразовыми, так и повторяющимися с возможностью настройки периодичности (ежедневно, еженедельно, ежемесячно, ежегодно). При выполнении периодической задачи она автоматически переносится на следующую дату в соответствии с правилом повторения.

На серверной стороне реализовано REST API, которое взаимодействует с подготовленным фронтендом. Все данные хранятся в базе данных SQLite.

## Выполненные задания со звёздочкой

В рамках проекта выполнены следующие задания повышенной сложности:

- **Полная реализация функции `NextDate`** — поддерживаются все правила повторения задач:
  - `d <число>` — повторение через указанное количество дней
  - `y` — ежегодное повторение
  - `w <дни недели>` — повторение в указанные дни недели (1-7, где 1 — понедельник, 7 — воскресенье)
  - `m <дни месяца> [месяцы]` — повторение в указанные дни месяца (поддерживаются отрицательные значения -1 и -2 для последнего и предпоследнего дней)
- **Поиск задач** — поддержка параметра `search` в GET-запросе `/api/tasks`:
  - Поиск по тексту в заголовке или комментарии
  - Поиск по дате в формате `DD.MM.YYYY`
- **Переменные окружения**:
  - `TODO_PORT` — для настройки порта сервера
  - `TODO_DBFILE` — для настройки пути к файлу базы данных

## Инструкция по запуску кода локально

### Требования

- Go версии 1.21 или выше
- SQLite (устанавливается автоматически через зависимость `modernc.org/sqlite`)

### Шаги для запуска

1. **Склонируйте репозиторий**
   git clone <ссылка_на_репозиторий>
   cd go_final_project

2. **Установите зависимости**
     go mod tidy

3. **Запустите сервер**
    go run main.go

4. **Откройте в браузере**
    http://localhost:7540

## Вы можете изменить настройки сервера с помощью переменных окружения:

# Изменить порт (по умолчанию 7540)
export TODO_PORT=8080

# Изменить путь к файлу базы данных (по умолчанию scheduler.db)
export TODO_DBFILE=./data/scheduler.db

# Запуск с пользовательскими настройками
go run main.go
